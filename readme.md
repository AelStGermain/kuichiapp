# Kuichi

**Kuichi** es una aplicación móvil desarrollada con Angular e Ionic que permite a los usuarios buscar ofertas veterinarias, registrar mascotas y gestionar autenticación simulada.

## Características

- Autenticación simulada con email y contraseña
- Navegación protegida mediante rutas con guardias
- Interfaz responsiva con barra de navegación adaptativa
- Arquitectura moderna basada en componentes standalone

## Tecnologías utilizadas

- Angular 17
- Ionic Framework
- TypeScript
- SCSS
